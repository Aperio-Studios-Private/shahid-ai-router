# Report Templates

## Feature plan
Feature ID; PRD refs; repository state; research URLs/dates; verified facts; assumptions; options; design; affected files; dependencies; security/privacy risks; failure modes; tasks; acceptance criteria; tests; rollback; reviewer findings; plan status.

## Feature completion
Feature ID; PASS/FAIL/BLOCKED; requirements; tasks; files; decisions; exact commands/tests/results; build/lint/typecheck; independent review; security findings; fixes; regression; docs updated; residual risks; evidence; next eligible feature.

## Audit finding
Finding ID; severity; category; affected component; description; evidence/reproduction; impact; recommendation; owner; status; retest evidence.
