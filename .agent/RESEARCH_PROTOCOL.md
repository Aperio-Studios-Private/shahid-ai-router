# Research Protocol

Prefer official API docs, release notes, official repositories/issues and standards. Community sources are supplementary.

Verify current stable versions, maintenance, license, platform support, security advisories, endpoints, auth, request/response schemas, streaming, tool calling and agent configuration. Record URL, access date, version and finding. Separate facts from assumptions.

Discover relevant skills/MCPs, but do not install merely because available. Review permissions, provenance, maintenance, license and security. Ask approval for external account access, spending, sensitive permissions or destructive actions. If no suitable MCP exists, use documented manual research; never invent a tool.

Save notes under `audits/planning/<feature-id>-research.md`.
